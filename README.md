# Further — travel guide

A bilingual (RU/EN) responsive travel discovery website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — destination discovery homepage
- `city.html?city=rome` — reusable city guide template (being added next)

## Features
- Russian / English language switch
- Light / dark theme (saved in localStorage)
- Destination category filters
- Responsive layout for mobile and desktop
- GitHub Pages friendly URLs

## Run locally
Open `index.html` in a browser or use any static file server.

## Publish with GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
